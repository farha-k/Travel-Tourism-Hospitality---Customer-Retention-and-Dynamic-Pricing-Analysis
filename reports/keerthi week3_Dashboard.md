# Week 3: Power BI Dashboard Development

## Objective
To create an interactive Power BI dashboard for visualizing hotel booking data and generating business insights.

---

## Dataset Information
- **Dataset:** Hotel Booking Dataset
- **Records:** ~119,390 rows
- **Columns:** 32 features
- **Source:** CSV file

---

# Dashboard Visualizations Created

## 1. Hotel Type Analysis
- **Visualization:** Bar Chart
- **Analysis:** Compared City Hotel and Resort Hotel bookings.
- **Insight:** City Hotels received more bookings compared to Resort Hotels.

---

## 2. Cancellation Analysis
- **Visualization:** Pie Chart
- **Analysis:** Analyzed booking cancellation distribution.
- **Insight:** Around 44K bookings were canceled.

---

## 3. Country-wise Booking Analysis
- **Visualization:** Bar Chart
- **Analysis:** Displayed top countries with highest bookings.
- **Insight:** Portugal (PRT) has the highest number of customers.

---

## 4. Cancellation by Hotel Type
- **Visualization:** Stacked Column Chart
- **Analysis:** Compared cancellations between City Hotels and Resort Hotels.
- **Insight:** City Hotels have higher cancellation counts.

---

## 5. Lead Time Analysis
- **Visualization:** Line Chart
- **Analysis:** Studied customer booking lead time.
- **Insight:** Average lead time is around 104 days, indicating customers book early.

---
